What it is

The HTPN Digital Showcase is the AI Team's public-facing portfolio website — a single link that presents all 16+ clinical digital tools built in-house by HTPN's frontline staff. It serves as the team's official digital identity: a credible, professional front door for sharing their work with hospital directors, KKM stakeholders, conference organisers, and peer hospitals across Malaysia.

Before the showcase site, each tool existed in isolation — links shared ad hoc via WhatsApp, with no central place to understand the full scope of what the team had built. The showcase solves that by bringing everything together: project descriptions, tech details, team credits, the innovation pipeline, the team's journey, and contact information — all in one polished, always-accessible URL.

Key features & design decisions

🎨

GSAP-Animated Dark Teal Aesthetic

Smooth scroll animations, staggered card reveals, and a dark teal palette with the Urbanist typeface — modelled after modern portfolio sites like untold.site. Designed to look credible to external audiences, not just internal hospital stakeholders.

📄

Individual Project Pages

Each of the 16+ tools has a dedicated page with clinical context, tech specs, UX feature breakdown, workflow summary, and a live demo link — structured like a product brief, not a slide deck.

📱

Mobile-First & Shareable

Fully responsive and accessible on any phone — built to be shared via a single WhatsApp link and read on a mobile screen by a hospital director, conference organiser, or visiting delegation.

☁️

Vercel Deployment

Migrated from Netlify to Vercel to resolve build credit and peer dependency issues. CI/CD via GitHub — changes pushed to the repo deploy automatically to the live URL.

🗂️

Category Filter

Projects are filterable by journey type — Patient, Doctor, Management — allowing different audiences to quickly find tools relevant to their domain.

🔗

Single Source of Truth

Replaces scattered WhatsApp links, email attachments, and verbal descriptions with one canonical URL representing everything the AI Team has built, deployed, and is working on.

Tech stack & build approach

Built using Vite + React 18 as a single-page application, with GSAP (GreenSock Animation Platform) powering scroll-triggered and entrance animations. Styled with custom CSS using the Urbanist typeface throughout. The project is maintained on GitHub and deployed to Vercel via automatic CI/CD — any update pushed to the repository goes live immediately.

The site was built using the AI Team's signature "vibe coding" approach — rapid prototyping with AI as the technical driver — starting as a single HTML file, progressively migrated to a full React + Vite architecture as the tool count and page complexity grew.

Who it is for & why it matters

The showcase site is built for four key audiences: hospital directors and KKM leadership who need a quick, credible overview of what the team has built; conference organisers and academic institutions evaluating the team for speaking invitations; peer hospitals considering adopting or adapting these tools; and the general public interested in what a government hospital in Malaysia can build from within.

It is also a living record of institutional memory — a permanent, indexed documentation of every tool the AI Team has built since 2024, ensuring that the work is not lost to WhatsApp chats, shared drives, or staff transfers. As the team grows and more tools are added, the showcase scales with it.
